# Contributing to iCustomer repositories

Use a branch and pull request for every change to a protected branch. Include the associated Linear issue identifier in the branch name or pull request title, and complete the pull request template.

The shared branch strategy, review expectations, release labels, and future workflow policy are maintained in the [engineering-workflows repository](https://github.com/icustomerai/engineering-workflows).

Application repositories own their own build, deployment, and runtime documentation.
